# Features:

- /bxbot-dogpic - Gives a random dog picture
- /bxbot-joke - Tells a random dad joke
- /bxbot-ping - Get the bot ping
- /bxbot-catfact - Get random cat fact

# Try it:

[Live Demo](https://hackclub.enterprise.slack.com/archives/C0P5NE354)

### How to run it locally:
```
1. Install required packages: npm install
2. Rename .env.example into .env
3. Edit the .env to your values
4. Run the bot: node indes.js
```
